# Еливанс — демонстрационный сайт

Адаптивный одностраничный сайт салона красоты «Еливанс» (Королёв).

## Состав

- `index.html` — сайт со встроенными CSS и JavaScript и SVG-иконками;
- `assets/images/` — 17 локальных изображений в WebP (логотип, интерьер, услуги, мастера), без зависимости от внешних фотохостингов;
- `scripts/vendor_images.py` — разовая служебная утилита для загрузки изображений в репозиторий;
- `favicon.svg` — фирменная SVG-иконка;
- `.nojekyll` — вспомогательный файл для GitHub Pages (при необходимости).

## Публикация на GitHub Pages

Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, затем **main** и **/(root)** и сохраните настройки.

Адрес после включения Pages: https://proninmike3-cyber.github.io/elivans/

## Важно

Демонстрационный сайт. Перед продажей и коммерческой публикацией уточните актуальность цен, права на использование фотографий и логотипа, информацию о мастерах и ссылку записи. Все фотографии и логотип загружаются из папки `assets/images/` этого репозитория. Шрифты Google Fonts, интерактивная карта и ссылки записи используют внешние сервисы.

Админ-панель и собственная база данных отсутствуют.
