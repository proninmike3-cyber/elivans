# Еливанс — демонстрационный сайт

Адаптивный одностраничный сайт салона красоты «Еливанс» (Королёв).

## Состав

- `index.html` — сайт со встроенными CSS и JavaScript и SVG-иконками;
- `favicon.svg` — фирменная иконка;
- `.nojekyll` — вспомогательный файл для GitHub Pages (при необходимости).

## Публикация на GitHub Pages

Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, затем **main** и **/(root)** и сохраните настройки.

Адрес после включения Pages: https://proninmike3-cyber.github.io/elivans/

## Важно

Демонстрационный сайт. Перед продажей и коммерческой публикацией уточните актуальность цен, права на использование фотографий и логотипа, информацию о мастерах и ссылку записи. Часть изображений и шрифты загружаются из открытых внешних источников, поэтому требуется интернет.

Админ-панель и собственная база данных отсутствуют.
